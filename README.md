## Проекты

### [Симулятор экзамена и Асинхронный загрузчик](https://github.com/gentlemk/python-exam-simulator-async-downloader)

Приложение для моделирования конкурентного доступа к ресурсам и асинхронной загрузки данных.

- **Компетенции:**
  - Backend
  - асинхронность
  - многопроцессорность
- **Стек:** Python (`multiprocessing`, `asyncio`), `aiohttp`, `aiofiles`, `prettytable`.
- **Особенность:** Безопасная синхронизация общих данных через `Manager` (`DictProxy`, `Lock`), динамический консольный интерфейс и отказоустойчивая обработка ошибок.

### [MovieLens Analytics: Data Science & EDA Project](https://github.com/gentlemk/movielens-analytics-python)

Комплексный пайплайн для разведочного анализа данных (EDA) и статистической обработки датасета MovieLens.

- **Компетенции:**
  - Data Science
  - статистический анализ
  - NLP (обработка текстов)
  - ООП-архитектура

- **Стек:** Чистый Python (без `pandas`/`numpy` для демонстрации алгоритмического мышления), `pytest` (покрытие **300+ unit-тестами**), Jupyter Notebook.
- **Особенность:** Проектирование собственных структур данных и анализ смещений в оценках пользователей.

### [cpp-containers: Собственная реализация STL на C++20](https://github.com/gentlemk/cpp-containers)

Библиотека контейнеров (vector, list, map, set, stack, queue и др.), повторяющая поведение и интерфейс стандартной библиотеки шаблонов (STL).

- **Компетенции:**
  - Системное программирование
  - ООП
  - Работа с памятью
  - Шаблоны (C++20)
  - Алгоритмы и структуры данных (деревья, связные списки)
  - Тестирование
- **Стек:** C++20, GoogleTest (GTest), Makefile, RAII.
- **Особенность:** Ручное управление памятью и реализация алгоритмов «под капотом» без копирования кода STL.
